# MNA 回路解析ラボ

ずんだもんと四国めたんの掛け合いで、回路シミュレータが中で使っている **MNA(修正節点解析)** を1ステップずつ解説するページです。

題材は、電圧源1個・電流源1個・抵抗3本の回路です。行列の組み立て(スタンプ)と連立方程式の計算はページの中で実際に動いていて、部品の値を変えると図・行列・答えがすべて変わります。

## 内容(13章)

1. 全体の流れ / 回路図からネットリストへ / KCL で式を立てる
2. MNA の発想:電圧源の電流も未知数にする
3. スタンプ:抵抗 → GND につながる抵抗 → 電流源 → 電圧源
4. 完成した A x = Z を解き、KCL で検算する
5. 実験:わざと解けない回路にする(行列式が 0 になる)
6. 部品のばらつきとワーストケース解析 / 手計算の公式との照合

## 使い方

`index.html` を開き、「▶ 自動再生」または「次 ⏭」で進めます。「🔈 読み上げ」を押すと音声が流れます。

## ファイル構成

| パス | 内容 |
|---|---|
| `index.html` | ページ本体(外部ライブラリなし、Google Fonts のみ読み込み) |
| `img/` | 立ち絵 |
| `voice/` | 収録済みのセリフ音声と対応表 `manifest.json` |
| `tools/gen_voice.js` | セリフ音声を作り直すスクリプト |

## セリフを変えたとき

VOICEVOX を起動した状態で、次を実行します(Node.js 18 以上と ffmpeg が必要)。変わったセリフだけ作り直します。

```
node tools/gen_voice.js
```

## 画像・音声について

`img/` の立ち絵(坂本アヒル様の素材を縮小・加工したもの)と `voice/` の音声(VOICEVOX で生成)は、このページで使うためだけに置いています。素材として再利用・再配布しないでください。
立ち絵は配布元から、音声は VOICEVOX から各自で入手し、それぞれの規約に従ってください。

- ずんだもん・四国めたん キャラクター利用ガイドライン: https://zunko.jp/guideline.html
- VOICEVOX 音源利用規約: https://zunko.jp/con_ongen_kiyaku.html
